## 답을 보기 전에

1. 평균에 // 대신 /를 쓰는 이유는?
2. 이 문제에서 빈 리스트를 따로 검사할 필요가 있을까?

<details>
<summary>내 접근 · 모범답안 · 복습 해설</summary>

sum(arr) / len(arr)로 작성한 첫 풀이가 맞았습니다.

## 모범답안

```python
def solution(arr):
    return sum(arr) / len(arr)

print(solution([1, 2, 3, 4]))  # 2.5
print(solution([5, 5]))        # 5.0
```

합 10을 개수 4로 나누면 2.5입니다. //를 쓰면 몫 2가 되어 평균을 잃습니다. /는 이 정수 입력에서 float을 반환합니다. 길이가 1 이상이므로 0으로 나누지 않습니다. 입력 길이 m에 대해 시간 O(m), 추가 공간 O(1)입니다.

</details>
