# 나눗셈·몫·나머지 — /, //, %

[전체 목차](../../README.md) · [도구 목차](../README.md) · [이 장 목차](README.md)

## 세 연산을 구분하기

| 연산 | 뜻 | 예시 | 결과 |
| --- | --- | --- | --- |
| `/` | 일반 나눗셈 | `7 / 2` | `3.5` |
| `//` | 나눗셈 결과를 아래쪽 정수로 내림 | `7 // 2` | `3` |
| `%` | 나눈 뒤 남은 나머지 | `7 % 2` | `1` |

7을 2씩 묶으면 **3묶음이고 1이 남습니다.** 그래서 몫은 3, 나머지는 1입니다.

```python
print(7 / 2)   # 3.5
print(7 // 2)  # 3
print(7 % 2)   # 1
```

## 나누어떨어지는지 확인하기

**a를 b로 나누어떨어진다 → `a % b == 0`**입니다. b는 0이 아니어야 합니다.

```python
print(6 % 3 == 0)  # True: 6은 3의 배수, 3은 6의 약수
print(3 % 6)       # 3: 순서를 바꾸면 결과도 달라짐
```

하샤드 수에서는 a가 원래 수이고, b가 자릿수 합입니다.
예를 들어 18의 자릿수 합은 9이므로 `18 % 9 == 0`으로 확인합니다.

## 마지막 자리를 꺼내거나 제거하기

음이 아닌 정수에서 사용합니다.

```python
n = 1234
print(n % 10)   # 4: 마지막 한 자리
print(n // 10)  # 123: 마지막 한 자리 제거
print(n / 10)   # 123.4: 자릿수 제거용이 아님
```

위 코드는 결과를 출력할 뿐 n을 바꾸지 않습니다. n에 저장하려면 `n //= 10`으로 씁니다.

## 필요한 묶음 수 올림하기

a가 0 이상의 정수, b가 양의 정수일 때 `(a + b - 1) // b`입니다.
10명을 한 판 7조각 피자로 먹이려면 2판이 필요합니다.

```python
a, b = 10, 7
print((a + b - 1) // b)  # 2
```

## 음수와 0 주의

`//`는 단순히 소수 부분을 지우는 것이 아니라 **아래쪽으로 내립니다**.

```python
print(-7 // 2)  # -4
print(-7 % 2)   # 1
```

세 연산 모두 오른쪽에 0을 넣으면 ZeroDivisionError입니다.
