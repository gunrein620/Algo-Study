# 프로젝트 학습 메모리

기준일: 2026-09-24. 사용자 제공 이전 대화의 인수인계 내용을 요약했다.
실제 풀이를 새로 평가한 결과가 아니므로 이후 증거로 갱신한다.

## 목표와 배경

- 컴퓨터공학 전공. 스택·큐·연결리스트·트리·그래프, DFS/BFS 개념과 정렬 학습 경험이 있다.
- 목표: 10월 안으로 대기업 IT/SW 코딩테스트 대비. Python 구현 어휘를 빠르게 채워 Lv.1을 거쳐 Lv.2 핵심 유형을 구현한다.
- 현재 병목: 아이디어를 코드로 옮기는 속도, 내장함수 어휘, 인덱스/값/슬라이싱/자료형 구분.
- 인수인계 기준: Lv.0 중후반, Lv.1 맛보기 가능, Lv.1 안정권과 Lv.2 실전 구현력은 아직 부족하다고 본다.
- 강점: 핵심 논리를 생각하고 새 패턴을 다음 문제에 적용하는 속도가 빠르다.

## 이미 접한 것과 복습할 것

- 사용 경험: 반복/조건문, range, //와 %, 컴프리헨션, 제너레이터 표현식, join, sort/sorted, set, dict 매핑, Counter, gcd/lcm/isqrt, 기본 슬라이싱.
- 집중 복습: `arr[i]`와 `arr.index(x)`, 반복 변수는 값이라는 점, enumerate, 슬라이싱 끝 미포함, 문자열 불변성, sorted의 list 반환, map의 iterator 반환.
- 다음 도구: zip, deque, heapq, bisect, combinations/permutations, defaultdict, Counter 심화. 접했다는 것과 숙달했다는 것을 구분한다.

## 최근 확인한 복습 지점

- 2026-09-24, 자연수 뒤집기: 내림차순 정렬과 순서 뒤집기를 혼동했다.
  추가 질문의 핵심은 map 자체가 아니라 `str(n)[::-1]`처럼 함수 반환값에 바로 슬라이싱하는 문법이었다.
  사용자는 슬라이싱이 아직 익숙하지 않다고 했다. 중간 변수로 분리하고 실제 값·타입을 추적해 설명한다.
  설명을 들은 상태이며 독립 재풀이로 숙달 여부는 확인하지 않았다.
  기록: `review/2026-09-24-reverse-digits.md`.
- 2026-09-24, 정수 내림차순 배치: 정렬 선택은 맞았지만 문자마다 int를 적용한 결과를 join에 전달했다.
  join의 원소는 str여야 하며 최종 요구 타입에 따라 int 변환 시점이 달라짐을 설명했다.
  사용자가 `int(''.join(sorted(str(n), reverse=True)))`로 수정한 것을 확인했다.
  제출 통과나 독립 숙달은 미확인. 중간 값과 타입 추적, 이전 뒤집기 문제와의 비교가 복습 포인트다.
  기록: `review/2026-09-24-sort-digits-descending.md`.

## 학습 전략

1. Lv.0 50~70문제 정도로 구현 감각과 Python 어휘 회복.
2. 무작위 Lv.0 10문제 중 7~8개를 5분 내 도움 없이 풀면 Lv.1 병행.
3. Lv.1 30~50문제, Lv.2 60~100문제 이상을 방향으로 삼되 문제 수 자체를 목표로 강제하지 않는다.
4. Lv.2 완전탐색·해시·스택/큐·DFS/BFS·정렬·그리디·이분탐색·힙·기초 DP, 이후 쉬운 Lv.3 및 기업 기출.

기본 흐름은 문제 → 사용자 시도 → 코드/캡처 진단 → 적절한 도구 → 모범답안 → 재사용할 패턴이다.
시간이 촉박하므로 이미 있는 함수를 몰라 한 문제에 20~30분을 소비하게 하지 않는다.
교과서는 충분히 풀어서 쓰고, 대화 답변은 문제에 필요한 만큼 간결하게 한다.

## 유지 방식

이 파일은 저장소 안의 전용 학습 맥락이며 AGENTS.md가 읽도록 안내한다.
앱의 숨겨진 자동 메모리나 계정 전체 메모리를 활성화하는 설정 파일은 아니다.
새 대화도 이 프로젝트에서 시작한다. 학습 수준·선호가 바뀌면 해당 항목을 근거와 날짜로 수정한다.
