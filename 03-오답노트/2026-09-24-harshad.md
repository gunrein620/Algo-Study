# 하샤드 수 — 자릿수 합과 원본 보존

[전체 목차](../README.md) · [오답노트 목차](README.md) · [자릿수 합 교과서](../02-풀이-패턴/10-digits.md#digit-sum)

- 기록일: 2026-09-24
- 문제: 양의 정수 x가 자신의 자릿수 합으로 나누어떨어지는지 불리언으로 반환. 입력은 1~10,000.
- 진행: while문으로 시도하다 막혔고, 원본 x가 0이 되는 이유를 설명받은 뒤 이해했다고 표현함. sum/map 풀이를 선호함.
- 풀이 시간: 미기록. 플랫폼 제출 통과와 독립 재풀이는 미확인.

## 먼저 답해 볼 질문

1. `sum(map(int, str(18)))`이 9가 되는 과정을 설명할 수 있는가?
2. `while x > 0`에서 `x //= 10`을 반복하면 마지막 x는 무엇인가? 원래 수를 검사하려면 어떻게 해야 하는가?
3. `i =+ digit`과 `i += digit`은 어떻게 다른가?
4. `"true"`, `True`, `1 > 0`의 타입은? 비교식을 바로 return해도 되는가?

## 모범답안 — 이 풀이를 먼저 기억하기

```python
def solution(x):
    digit_sum = sum(map(int, str(x)))
    return x % digit_sum == 0

print(solution(18))  # True
print(solution(13))  # False
```

**자릿수 합 구하기 → 원래 수가 그 합으로 나누어떨어지는지 확인하기**입니다.
이 방식은 x를 바꾸지 않으므로 마지막에도 원래 입력값을 사용할 수 있습니다.

## 18을 넣고 단계별로 읽기

| 코드 | 값 또는 동작 |
| --- | --- |
| `str(18)` | 문자열 `"18"` |
| `map(int, "18")` | 문자 `"1"`, `"8"`을 정수 1, 8로 차례로 변환 |
| `sum(...)` | 1 + 8 = 9 |
| `18 % 9 == 0` | True |

중간 결과를 눈으로 보려고 나누어 쓰면 다음과 같습니다.

```python
x = 18
text = str(x)
digits = list(map(int, text))
digit_sum = sum(digits)

print(text)                # 18 (문자열)
print(digits)              # [1, 8]
print(digit_sum)           # 9
print(x % digit_sum == 0)  # True
```

list는 중간 결과 확인용입니다. 모범답안에서는 sum이 map의 결과를 직접 받아 더하므로 필요 없습니다.

## 내 실수 — 가장 중요했던 것은 원본 x가 사라진 것

`+=`와 `% 10`을 고친 뒤에도 아래 흐름은 남아 있었습니다.
원래 코드는 조건에 따라 `1 > 0` 또는 `1 < 0`을 반환했지만, 핵심 오류는 그 앞의 `x % i`였습니다.

```python
x = 13
i = 0

while x > 0:
    i += x % 10
    x //= 10

print(x)           # 0
print(i)           # 4
print(x % i == 0)  # True: 13이 아니라 0을 검사하고 있음
```

| 단계 | x의 변화 | 더한 자리 | 누적 합 i |
| --- | --- | --- | --- |
| 시작 | 13 | — | 0 |
| 첫 반복 | 13 → 1 | 3 | 3 |
| 두 번째 반복 | 1 → 0 | 1 | 4 |

필요한 검사는 `13 % 4 == 0`인데, 실제로는 `0 % 4 == 0`을 계산했습니다.
**나중에 다시 쓸 원본은 보존해야 합니다.**

## 함께 고친 부분

| 시도 | 실제 의미 | 기억할 수정 |
| --- | --- | --- |
| `x % 4` | 4로 나눈 나머지 | 마지막 한 자리는 `x % 10` |
| `i =+ ...` | 양수 부호를 붙인 값을 새로 대입 | 누적은 `i += ...`, 처음에 `i = 0` |
| `"true"`, `"false"` | 문자열 | 불리언 `True`, `False`가 필요 |
| `1 > 0`, `1 < 0` | 각각 True, False인 비교식 | 동작은 맞지만 원래 판별식을 직접 반환하면 충분 |

## while문으로 유지하려면

```python
def solution_while(x):
    original = x
    digit_sum = 0

    while x > 0:
        digit_sum += x % 10
        x //= 10

    return original % digit_sum == 0

print(solution_while(18))  # True
print(solution_while(13))  # False
```

원래 x를 original에 저장하고 마지막에 original을 검사합니다.
문제에서 x가 양수이므로 자릿수 합도 양수여서 0으로 나누지 않습니다.

자릿수가 d개일 때 문자열 변환 후 합산은 O(d) 시간이며 문자열 저장 공간은 O(d)입니다.
이 문제는 입력이 최대 10,000이므로 최대 5자리를 처리합니다.

## 이 문제에서 가져갈 것

1. **자릿수 합:** `sum(map(int, str(x)))`.
2. **원본 보존:** 반복문에서 바꾼 변수는 처음 입력값과 다를 수 있다.
3. **불리언 반환:** `return x % digit_sum == 0`처럼 비교식을 바로 반환한다.
