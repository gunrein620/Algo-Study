# map — 원소마다 같은 함수 적용하기

[전체 목차](../../README.md) · [도구 목차](../README.md) · [이 장 목차](README.md)

**`map(int, 대상)`은 대상에서 하나씩 꺼내 int로 바꾼다는 뜻입니다.**

## 바로 쓰는 예시

```python
text = "1234"
digits = list(map(int, text))

print(digits)  # [1, 2, 3, 4]
```

문자열도 한 글자씩 순회할 수 있습니다. `"1234"`에서 `"1"`, `"2"`, `"3"`, `"4"`를 꺼내 각각 정수로 바꿉니다.

## 두 인자는 각각 무엇인가?

```python
map(int, "1234")
#   ↑      ↑
# 적용 함수  하나씩 꺼낼 대상
```

첫 번째 자리에는 함수 자체인 `int`를 넣습니다. `int()`처럼 먼저 호출하는 것이 아닙니다.
두 번째 자리에는 문자열·리스트처럼 순회할 대상을 넣습니다.

## 결과가 리스트인지, 합인지에 따라 감싸기

| 필요한 결과 | 코드 | 결과 |
| --- | --- | --- |
| 정수 리스트 | `list(map(int, "1234"))` | `[1, 2, 3, 4]` |
| 정수들의 합 | `sum(map(int, "1234"))` | `10` |

map 자체는 list가 아니라 **변환 결과를 차례로 내놓는 iterator**를 반환합니다.
list는 그 결과를 모으고, sum은 그 결과를 더합니다. sum 앞에 list를 넣을 필요는 없습니다.

## 일반 for문으로 풀면

```python
answer = []
for ch in "1234":
    answer.append(int(ch))

print(answer)  # [1, 2, 3, 4]
```

조건 없이 같은 함수만 적용하면 map이 간결합니다. 필터 조건이나 계산식이 추가되면 컴프리헨션도 고려합니다.

## 주의할 점

- 원본 문자열이나 리스트는 바꾸지 않습니다.
- 빈 입력은 변환할 원소가 없습니다. list로 모으면 `[]`, sum으로 더하면 `0`입니다.
- `int`로 바꿀 수 없는 문자에는 ValueError가 납니다. 변환은 결과를 꺼낼 때 실행됩니다.
- 같은 map 객체를 끝까지 소비하면 다시 사용할 때 아무 원소도 남지 않습니다.

```python
converted = map(int, ["1", "2", "3"])
print(list(converted))  # [1, 2, 3]
print(list(converted))  # []: 앞에서 모두 꺼냈음
```
