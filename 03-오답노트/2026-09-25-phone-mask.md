# 핸드폰 번호 가리기 — 위치·문자·슬라이싱 연결하기

[전체 목차](../README.md) · [오답노트 목차](README.md) · [복습 목차](../04-복습노트/README.md) · [슬라이싱 교과서](../01-파이썬-도구/06-문법/slicing.md)

- 기록일: 2026-09-25
- 문제: 길이 4~20인 문자열의 마지막 4글자는 그대로 두고 앞부분을 별표로 바꾸기.
- 내 상태: 역순 순회 설명을 듣고 올바른 반복문 풀이를 완성함. 슬라이싱 개념은 아직 익숙하지 않다고 표현함.
- 제출 통과와 슬라이싱 독립 재풀이는 미확인. 최종 반복문 풀이를 틀린 풀이로 분류하지 않는다.

## 먼저 말로 답하기

`s = "321432"`라고 놓고 답을 가린 채 생각합니다.

1. `len(s)`는 무엇이고 마지막 인덱스는 무엇인가?
2. `for i in range(5, -1, -1)`의 i와 `for ch in reversed(s)`의 ch는 무엇이 다른가?
3. `s[-4]`, `s[-4:]`, `s[:-4]`, `s[::-1]`은 각각 어떤 값인가?
4. `s[-4:]`의 -4는 시작 위치인가, 이동 방향인가?
5. 길이가 정확히 4일 때 별표는 몇 개 필요한가?

<details>
<summary>해설 1 — 내 풀이와 모범답안 연결하기</summary>

## 내가 완성한 풀이 — 정답

```python
def solution(phone_number):
    answer = []
    cnt = 1
    for i in reversed(phone_number):
        if cnt <= 4:
            answer.append(i)
        else:
            answer.append('*')
        cnt += 1
    return ''.join(reversed(answer))

print(solution("321432"))  # **1432
print(solution("1234"))    # 1234
```

문자열을 뒤에서부터 읽고 처음 4글자를 유지했습니다. answer에는 `['2', '3', '4', '1', '*', '*']`가 들어갑니다.
마지막에 다시 뒤집어 합치므로 결과는 `"**1432"`입니다. 두 번 뒤집는 이유를 설명할 수 있으면 이 풀이도 충분히 이해한 것입니다.

## 모범답안 — 보존할 구간을 바로 가져오기

```python
def solution(phone_number):
    return '*' * (len(phone_number) - 4) + phone_number[-4:]

print(solution("01033334444"))  # *******4444
print(solution("027778888"))    # *****8888
print(solution("321432"))       # **1432
print(solution("1234"))         # 1234
```

한 줄을 외우기 전에 아래처럼 두 조각으로 나누어 봅니다.

```python
phone_number = "321432"
hidden_count = len(phone_number) - 4
hidden = '*' * hidden_count
last_four = phone_number[-4:]
answer = hidden + last_four

print(hidden_count)  # 2
print(hidden)        # **
print(last_four)     # 1432
print(answer)        # **1432
```

| 내 반복문에서 한 일 | 슬라이싱 풀이에서 표현 |
| --- | --- |
| 뒤에서 읽은 4글자를 담고 나중에 순서를 복구 | `phone_number[-4:]`로 원래 순서 그대로 추출 |
| 나머지 글자마다 별표 추가 | `'*' * (len(phone_number) - 4)` |
| 조각들을 최종 문자열로 합침 | 두 문자열을 `+`로 연결 |

두 풀이 모두 길이 n에 대해 시간 O(n), 결과를 포함한 공간 O(n)입니다. 슬라이싱은 더 짧고 구간을 보존한다는 의도가 직접 보입니다.

<summary>해설 2 — 내가 헷갈린 인덱스와 음수 위치</summary>

## 길이와 위치는 다르다

| 문자 | 3 | 2 | 1 | 4 | 3 | 2 |
| --- | --- | --- | --- | --- | --- | --- |
| 앞에서 센 위치 | 0 | 1 | 2 | 3 | 4 | 5 |
| 뒤에서 센 위치 | -6 | -5 | -4 | -3 | -2 | -1 |

길이는 6이지만 위치는 0부터 세므로 마지막 위치는 5입니다.
음수 위치는 오른쪽 끝을 -1로 놓고 셉니다. 같은 문자 `"1"`을 `s[2]` 또는 `s[-4]`로 꺼낼 수 있습니다.

| 반복 방식 | 반복 변수에 들어가는 값 | 타입 |
| --- | --- | --- |
| `range(len(s) - 1, -1, -1)` | 5, 4, 3, 2, 1, 0 | int |
| `reversed(s)` | '2', '3', '4', '1', '2', '3' | str |

둘 다 6번 반복합니다. 횟수가 같다고 반복 변수의 값까지 같은 것은 아닙니다.
인덱스 i를 받았다면 `s[i]`로 문자를 꺼냅니다. reversed(s)는 문자를 바로 줍니다.
`range(s, -1)`은 문자열을 정수 범위의 시작값으로 넣어서 TypeError가 납니다.

## -4는 방향이 아니라 시작 위치

```text
s[시작:끝:간격]
s[-4:        ]  → 뒤에서 네 번째 위치부터 끝까지, 기본 간격 +1
s[  :  :   -1]  → 전체를 간격 -1로 거꾸로
```

`"321432"`에서 -4 위치는 `"1"`입니다. 여기서 오른쪽으로 `1 → 4 → 3 → 2`를 읽으므로 `"1432"`가 됩니다.
**음수 인덱스는 위치를 뒤에서 세는 표기이고, 역순 여부는 간격의 부호가 결정합니다.**

| 표현 | 의미 | 결과 |
| --- | --- | --- |
| `s[-4]` | 뒤에서 네 번째 문자 하나 | `"1"` |
| `s[-4:]` | 뒤에서 네 번째부터 끝까지 | `"1432"` |
| `s[:-4]` | 처음부터 뒤에서 네 번째 직전까지 | `"32"` |
| `s[::-1]` | 전체 역순 | `"234123"` |

문자열에서는 한 문자도 str입니다. 콜론 없는 인덱싱은 하나, 콜론 있는 슬라이싱은 구간을 꺼낸다는 차이입니다.
길이가 4라면 `len(s) - 4`는 0, 별표 0개는 빈 문자열이며 `s[-4:]`는 전체입니다.

</details>

## 5분 연습 — 답을 보기 전에 직접 적기

헷갈린 지점을 구분하려고 중복 문자가 없는 `s = "abcdef"`를 사용합니다.

| 표현 | 내가 예상한 결과 |
| --- | --- |
| `s[-4]` | |
| `s[-4:]` | |
| `s[:-4]` | |
| `s[1:4]` | |
| `s[-4:-1]` | |
| `s[::-1]` | |

추가로 `"1234"`와 `"01234"`를 가리는 함수를 답 없이 작성합니다. `"01234"`는 처음의 0도 문자 한 자리로 세야 합니다.

<details>
<summary>연습 정답과 이유</summary>

```python
s = "abcdef"
print(s[-4])     # c
print(s[-4:])    # cdef
print(s[:-4])    # ab
print(s[1:4])    # bcd
print(s[-4:-1])  # cde
print(s[::-1])   # fedcba
```

시작 위치는 포함하고 끝 위치는 제외합니다. `s[-4:-1]`은 c부터 마지막 문자 f 직전까지이므로 cde입니다.
마스킹 결과는 각각 `"1234"`, `"*1234"`입니다.

</details>

## 이번에 가져갈 것

1. **위치와 값:** range는 위치로 쓸 정수를 만들고, reversed(문자열)는 문자를 꺼낸다.
2. **위치와 방향:** `[-4:]`는 마지막 4글자, `[::-1]`은 전체 뒤집기.
3. **구간 보존:** 일부만 남기는 문제에서는 필요한 구간을 슬라이싱으로 바로 가져올 수 있다.
