# 문자열 내 p와 y의 개수 — 대소문자 통일 후 개수 비교

[전체 목차](../README.md) · [오답노트 목차](README.md) · [대소문자 교과서](../01-파이썬-도구/02-문자열/case.md) · [count 교과서](../01-파이썬-도구/03-리스트/count.md)

- 기록일: 2026-09-24
- 문제: 대소문자를 구별하지 않고 p와 y의 개수를 비교해 같으면 True, 다르면 False 반환. 둘 다 없으면 True.
- 진행: 첫 반복문 풀이의 로직은 맞음. lower/count 풀이를 설명받고 비교 기록을 요청함.
- 제출 통과·독립 재풀이는 미확인. 틀린 풀이를 고치는 기록이 아니라 Python 도구를 익히는 복습 기록.

## 먼저 답해 볼 질문

1. 대소문자를 구별하지 않을 때, 비교 전에 문자열을 어떻게 바꾸면 편할까?
2. `s.lower()`만 호출해도 s가 바뀔까? `s = s.lower()`라고 쓰는 이유는?
3. `"abc"`에서 p와 y의 개수를 비교하면 왜 True일까?
4. 내 첫 풀이의 `answer = True`를 지워도 되는 이유는?

## 모범답안

```python
def solution(s):
    s = s.lower()
    return s.count('p') == s.count('y')

print(solution("pPoooyY"))  # True
print(solution("Pyy"))     # False
print(solution("abc"))     # True
```

**소문자로 통일 → 각각 개수 세기 → 개수 비교** 순서입니다.
`lower()`와 `count()`는 문자열에서 호출하는 메서드이며 import 없이 사용합니다.

## 내가 처음 작성한 풀이 — 이 방식도 정답

```python
def solution(s):
    answer = True

    cnt_p = 0
    cnt_y = 0

    for i in s:
        if i == 'p' or i == 'P':
            cnt_p += 1
        if i == 'y' or i == 'Y':
            cnt_y += 1

    return cnt_p == cnt_y

print(solution("pPoooyY"))  # True
print(solution("Pyy"))     # False
print(solution("abc"))     # True
```

`for i in s`의 i는 인덱스가 아니라 문자 하나입니다.
각 문자가 p/P이면 cnt_p, y/Y이면 cnt_y에 1을 더하므로 논리가 맞습니다.
두 if를 따로 써도 문제없습니다. 한 문자가 p이면서 y일 수는 없습니다.
`answer`는 반환하거나 계산에 쓰지 않으므로 `answer = True`만 삭제해도 됩니다.

## 두 풀이의 연결

| 내가 직접 처리한 부분 | 메서드로 표현 |
| --- | --- |
| p/P, y/Y를 각각 검사 | `s.lower()`로 먼저 소문자로 통일 |
| cnt_p를 0부터 누적 | `s.count('p')` |
| cnt_y를 0부터 누적 | `s.count('y')` |
| `cnt_p == cnt_y` 반환 | 두 count 결과를 비교해서 반환 |

## 실제 값과 타입으로 읽기

입력이 `"pPoooyY"`일 때:

| 표현 | 결과 | 타입 |
| --- | --- | --- |
| `s.lower()` | `"ppoooyy"` | str |
| `s.count('p')` — 소문자로 바꾼 뒤 | 2 | int |
| `s.count('y')` — 소문자로 바꾼 뒤 | 2 | int |
| `2 == 2` | True | bool |

`count()` 자체는 대소문자를 구분합니다. 그래서 먼저 통일합니다.
`lower()`는 원본 문자열을 수정하지 않고 새 문자열을 반환하므로 결과를 저장해야 합니다.

```python
s = "Pyy"
print(s.count('p'))  # 0: 대문자 P는 소문자 p와 다름

lowered = s.lower()
print(s)                   # Pyy: 기존 문자열은 그대로
print(lowered)             # pyy
print(lowered.count('p'))  # 1
print(lowered.count('y'))  # 2
```

모범답안의 `s = s.lower()`는 새 문자열을 같은 변수 s에 다시 저장한 것입니다.

p와 y가 모두 없다면 두 count 결과가 0이므로 `0 == 0`은 True입니다.
별도 if문이 필요 없으며, 비교 결과는 문자열 `"True"`가 아닌 불리언 True/False입니다.

## 복잡도 비교

문자열 길이가 m일 때 두 풀이 모두 시간 O(m)입니다.
첫 풀이는 추가 공간 O(1), lower/count 풀이는 소문자 문자열을 저장하므로 추가 공간 O(m)입니다.
메서드 풀이도 문자열을 순회합니다. 여기서 얻는 이점은 직접 작성할 코드가 줄고 의도가 잘 드러난다는 것입니다.

## 이 문제에서 가져갈 것

1. **대소문자 무시:** 먼저 `s = s.lower()`로 통일한다.
2. **문자 개수:** `s.count('p')`로 구한다. 없으면 0이다.
3. **비교 결과 반환:** `return 개수1 == 개수2`로 불리언을 바로 반환한다.
