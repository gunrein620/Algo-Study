# 자연수 뒤집어 배열로 만들기

[복습 목차](README.md) · [프로그래머스 문제](https://school.programmers.co.kr/learn/courses/30/lessons/12932)

- 기록일: 2026-09-24
- 조건: 10,000,000,000 이하의 자연수 n의 자릿수를 역순의 정수 리스트로 반환.
- 진행: 직접 풀이를 시도했으나 일부 테스트 실패. 설명을 들었으며 슬라이싱이 아직 익숙하지 않다고 표현함.
- 풀이 시간: 미기록. 수정 코드의 플랫폼 재제출·독립 재풀이는 확인하지 않음.

## 먼저 답해 볼 질문

1. 13245의 자릿수를 내림차순 정렬한 결과와 원래 순서를 뒤집은 결과는 어떻게 다른가?
2. `str(n)[::-1]`을 중간 변수에 저장하는 두 줄 코드로 나눌 수 있는가?
3. `str(n)` 바로 뒤에 `[::-1]`을 붙일 수 있는 이유는 무엇인가? 그 결과의 타입은?
4. 1200을 뒤집은 배열에서 0 두 개를 유지하려면 어느 단계에서 int를 적용해야 하는가?

## 내 시도와 놓친 점

```python
def solution(n):
    return list(map(int, sorted(str(n), reverse=True)))

assert solution(12345) == [5, 4, 3, 2, 1]  # 예제에서는 우연히 같음
assert solution(13245) == [5, 4, 3, 2, 1]  # 요구 결과 [5, 4, 2, 3, 1]과 다름
```

문자열로 바꾸고 각 문자를 정수 리스트로 만드는 방향은 맞았습니다.
오류는 `sorted(str(n), reverse=True)`에서 **역순을 내림차순 정렬로 처리한 것**입니다.
예제 12345는 정렬과 뒤집기의 결과가 같아서 차이가 드러나지 않았습니다.

## 실제로 낯설었던 문법

핵심 질문은 map의 두 번째 인자 역할보다 **`str(n)` 바로 옆에 `[::-1]`을 붙일 수 있는가**였습니다.
`str(n)`의 결과인 문자열에 바로 슬라이싱하는 것이므로 가능합니다.

```python
n = 13245
s = str(n)          # "13245"
reversed_s = s[::-1] # "54231"
assert str(n)[::-1] == reversed_s
```

자세한 문법과 다른 예시는 [교과서: 함수 반환값에 슬라이싱하기](../python/syntax/README.md#slice-return-value)에서 확인합니다.

## 모범답안

```python
def solution(n):
    return list(map(int, str(n)[::-1]))

assert solution(12345) == [5, 4, 3, 2, 1]
assert solution(13245) == [5, 4, 2, 3, 1]
assert solution(1200) == [0, 0, 2, 1]
assert solution(7) == [7]
assert solution(10_000_000_000) == [0] * 10 + [1]
```

문자열 변환 → 역순 문자열 → 문자마다 int 변환 → list로 수집하는 흐름입니다.
자릿수 d개에 대해 문자열 변환 이후의 순회·슬라이싱은 O(d) 시간, 추가 공간은 O(d)입니다.
뒤집은 문자열 전체를 int로 만들면 앞의 0이 사라집니다. 각 문자를 개별 변환해야 합니다.

## 이 문제에서 가져갈 것

1. 내림차순 정렬과 현재 순서 뒤집기는 다르다.
2. 함수 반환값이 문자열·리스트이면 바로 인덱싱이나 슬라이싱을 적용할 수 있다.
3. 낯선 연결 표현식은 중간 변수로 나누고 실제 값과 타입을 따라간다.
