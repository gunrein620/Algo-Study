조건 표현식으로 Even과 Odd를 선택한 첫 풀이가 맞았습니다.

## 모범답안

```python
def solution(num):
    return "Even" if num % 2 == 0 else "Odd"

print(solution(0))   # Even
print(solution(-3))  # Odd
print(solution(4))   # Even
```

`참일_때_값 if 조건 else 거짓일_때_값`입니다. 0 % 2는 0, -3 % 2는 1이므로 같은 조건으로 판별합니다. 이 문제의 반환 타입은 bool이 아니라 문자열입니다.
