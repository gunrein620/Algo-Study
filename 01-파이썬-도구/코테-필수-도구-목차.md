# 코테 필수 함수·문법 학습 목차

[전체 목차](../README.md) · [도구 목차](README.md) · [함수 이름으로 찾기](함수-찾아보기.md)

코테에서 자주 쓰는 도구를 **필요한 작업 → 도구 이름 → 설명 문서**로 찾는 목차입니다.
함수뿐 아니라 메서드, 문법, 표준 라이브러리도 포함합니다. 전부 암기하고 시작하기보다, 어떤 기능이 있는지 먼저 훑고 문제에서 필요할 때 다시 찾아봅니다.

## 읽는 순서

1. **기본 도구:** 아래 01~06을 순서대로 훑으며 처음 보는 이름을 찾습니다.
2. **이번 문제에서 먼저 익힐 것:** `divmod`, f-string의 `:02d`, 범위를 제한하는 `min`·`max`입니다.
3. **유형별 확장:** 기본 도구를 사용하면서 큐·빈도·탐색 등 필요한 유형의 도구를 추가합니다.

이 목록은 숙달 완료 기록이 아닙니다. “상세 문서 미작성”은 저장소에 전용 설명이 아직 없다는 뜻입니다. 기존 문서 링크도 현재 설명하는 범위를 표시했습니다.
