# 인덱싱·슬라이싱·뒤집기

[전체 목차](../../README.md) · [도구 목차](../README.md) · [이 장 목차](README.md)

`arr[start:end:step]`은 지정한 구간을 추출합니다. 리스트는 새 리스트(얕은 복사), 문자열은 문자열입니다.
범위를 넘어가는 슬라이스는 잘라서 처리하지만, 단일 인덱싱은 범위를 벗어나면 IndexError입니다.
step은 0일 수 없습니다. 음수 step에서는 진행 방향도 반대입니다.

```python
arr = [1, 2, 3, 4, 5]
assert arr[1:4] == [2, 3, 4]
assert arr[:3] == [1, 2, 3]
assert arr[2:] == [3, 4, 5]
assert arr[:] == [1, 2, 3, 4, 5]
assert arr[::2] == [1, 3, 5]
assert arr[::-1] == [5, 4, 3, 2, 1]
assert arr[:-1] == [1, 2, 3, 4]
assert arr[-1:] == [5]
assert arr[99:] == []
assert [][-1:] == []
```

`arr[-1]`은 마지막 **값** 5, `arr[-1:]`은 마지막 원소를 담은 **리스트** `[5]`입니다.
추출 길이가 k인 리스트/문자열 슬라이스는 일반적으로 O(k) 시간과 결과 공간이 필요합니다.
적용 예시: [한 칸 회전](../../02-풀이-패턴/06-rotate.md) · [묶음 자르기·일정 간격 추출](../../02-풀이-패턴/07-chunk-step.md).

### 함수 반환값에도 바로 슬라이싱하기

`[]`는 변수 이름 뒤에만 붙이는 문법이 아닙니다. **계산 결과가 문자열이나 리스트처럼
슬라이싱을 지원하는 값이면 그 표현식 뒤에 바로 붙일 수 있습니다.**

```python
n = 13245
s = str(n)
reversed_s = s[::-1]
assert reversed_s == "54231"
assert str(n)[::-1] == reversed_s
assert str(n)[0] == "1"
assert str(n)[1:3] == "32"
```

`str(n)[::-1]`은 `str(n)`을 먼저 계산하고, 반환된 `"13245"`에 `[::-1]`을 적용합니다.
즉 `"13245"[::-1]`과 같고 결과는 문자열 `"54231"`입니다. 중간 변수에 저장하는 단계를 생략한 것입니다.
함수라서 가능한 것이 아니라 **반환값이 슬라이싱을 지원하기 때문에** 가능합니다.
예를 들어 `len("abc")`는 정수 3을 반환하므로 뒤에 `[::-1]`을 붙이면 TypeError입니다.

`[::-1]`에서는 start와 end를 생략하고 step을 -1로 지정합니다.
음수 방향의 기본 범위 전체를 한 칸씩 거꾸로 읽으므로 방문 인덱스는 4 → 3 → 2 → 1 → 0입니다.
문자열을 뒤집어도 결과는 문자열이고, 원본은 변하지 않습니다. 빈 문자열은 그대로 빈 문자열입니다.

**정렬과 뒤집기도 구분합니다.** `sorted(..., reverse=True)`는 값의 크기에 따라 재배치하고,
`[::-1]`은 현재 순서만 반대로 만듭니다.

```python
assert sorted("13245", reverse=True) == ["5", "4", "3", "2", "1"]
assert "13245"[::-1] == "54231"
assert ""[::-1] == ""
```
