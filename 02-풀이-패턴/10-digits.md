## 1. 자릿수 합 — 이 코드부터 익히기

```python
n = 1234

digit_sum = sum(map(int, str(n)))
print(digit_sum)  # 10
```

`digit_sum`은 “자릿수의 합”을 담는 변수입니다. **문자열로 바꾸기 → 문자마다 숫자로 바꾸기 → 더하기** 순서예요.

### 한 단계씩 나누면

```python
n = 1234

text = str(n)                  # "1234"
digits = list(map(int, text))  # [1, 2, 3, 4]
digit_sum = sum(digits)       # 10

print(digit_sum)  # 10
```

| 단계 | 실제 값 | 왜 필요한가? |
| --- | --- | --- |
| `str(n)` | `"1234"` | 정수 1234를 한 글자씩 꺼낼 수 있는 문자열로 바꿈 |
| 문자열에서 하나씩 꺼냄 | `"1"`, `"2"`, `"3"`, `"4"` | 각 글자가 숫자의 한 자리에 해당 |
| `int`를 각각 적용 | `1`, `2`, `3`, `4` | 문자 상태로는 숫자 덧셈을 할 수 없으므로 변환 |
| `sum`으로 더함 | `10` | 1 + 2 + 3 + 4 |

여기서 list는 **중간 결과를 눈으로 확인하려고** 사용했습니다.
실제 풀이에서는 sum이 map의 결과를 하나씩 받아 더하므로 `sum(map(int, str(n)))`이면 충분합니다.

### map이 낯설면 같은 일을 for문으로 보기

```python
n = 1234
digit_sum = 0

for ch in str(n):
    digit_sum += int(ch)

print(digit_sum)  # 10
```

`ch`는 인덱스가 아니라 **문자 하나**입니다. `+=`는 기존 값에 더해서 저장한다는 뜻입니다.

| 반복 | ch | int(ch) | 누적 합 digit_sum |
| --- | --- | --- | --- |
| 1번째 | `"1"` | 1 | 0 + 1 = 1 |
| 2번째 | `"2"` | 2 | 1 + 2 = 3 |
| 3번째 | `"3"` | 3 | 3 + 3 = 6 |
| 4번째 | `"4"` | 4 | 6 + 4 = 10 |

**이건 코테에서 자주 쓰니 챙겨라: 자릿수 합은 `sum(map(int, str(n)))`.**
이 코드는 n을 바꾸지 않습니다. n이 0이면 합도 0입니다. 음수는 '-'가 포함되므로 절댓값의 자릿수를 원하면 먼저 `abs(n)`을 사용합니다.

## 2. 하샤드 수에 연결하기

필요한 일은 두 가지입니다.

1. x의 자릿수 합을 구합니다.
2. **원래 x를 그 합으로 나눴을 때 나머지가 0인지** 확인합니다.

18이라면 1 + 8 = 9, 18을 9로 나눈 나머지가 0이므로 True입니다.
13이라면 1 + 3 = 4, 13을 4로 나눈 나머지가 1이므로 False입니다.

<details>
<summary>적용 코드 확인 — 먼저 직접 연결해 본 뒤 펼치기</summary>

```python
def solution(x):
    digit_sum = sum(map(int, str(x)))
    return x % digit_sum == 0

print(solution(18))  # True
print(solution(13))  # False
```

`x % digit_sum == 0` 자체가 True 또는 False이므로 if문으로 다시 감쌀 필요가 없습니다.
문제의 x는 1 이상이므로 자릿수 합도 1 이상이고, 0으로 나눌 일이 없습니다.

</details>

## 3. 숫자로 한 자리씩 꺼내는 방법 — 필요할 때 읽기

문자열 방식이 이해됐다면 여기까지 한꺼번에 외울 필요는 없습니다.
`% 10`과 `// 10`을 이용해도 자릿수를 꺼낼 수 있다는 보조 설명입니다.

<details>
<summary>몫·나머지 방식과 while문 펼치기</summary>

| 하고 싶은 일 | 코드 | 결과 |
| --- | --- | --- |
| 마지막 한 자리 꺼내기 | `1234 % 10` | 4 |
| 마지막 한 자리 제거 | `1234 // 10` | 123 |
| 마지막 두 자리 꺼내기 | `1234 % 100` | 34 |
| 마지막 두 자리 제거 | `1234 // 100` | 12 |

`/ 10`은 123.4처럼 나누는 것이고, `// 10`은 몫 123을 남기는 것입니다.

```python
n = 1234
remaining = n  # 원래 n은 보존하고 이 복사본을 줄임
digit_sum = 0

while remaining > 0:
    digit = remaining % 10  # 마지막 자리 꺼내기
    digit_sum += digit     # 그 자리를 합에 더하기
    remaining //= 10       # 처리한 마지막 자리 제거

print(digit_sum)  # 10
print(n)          # 1234: 원본은 그대로
```

| 반복 전 remaining | 꺼낸 자리 | 누적 합 | 반복 후 remaining |
| --- | --- | --- | --- |
| 1234 | 4 | 4 | 123 |
| 123 | 3 | 7 | 12 |
| 12 | 2 | 9 | 1 |
| 1 | 1 | 10 | 0 |

remaining이 0이 되면 끝납니다. `> 1`이면 마지막에 남은 1을 처리하지 못합니다.
remaining을 줄이는 줄이 없으면 같은 숫자로 계속 반복하게 됩니다.
이 방식은 음이 아닌 정수에 적용하며, 0이면 반복 없이 합 0을 얻습니다.

`digit_sum += digit`은 누적 덧셈이지만 `digit_sum =+ digit`은 양수 부호가 붙은 digit을 새로 대입하는 것입니다.

</details>

## 4. 자릿수를 뒤집은 정수 리스트 만들기

합이 아니라 **역순의 배열**이 필요하면 sum 대신 list로 모읍니다.

```python
n = 13245
answer = list(map(int, str(n)[::-1]))

print(answer)  # [5, 4, 2, 3, 1]
```

`"13245"` → `"54231"` → 각 문자를 int로 변환 → `[5, 4, 2, 3, 1]` 순서입니다.
1200도 같은 방법으로 `[0, 0, 2, 1]`이 됩니다. 문자열 전체를 먼저 int로 바꾸면 앞의 0이 사라지므로 각 문자에 적용합니다.
