# 01. 내장함수와 메서드

[전체 목차](../../README.md)

함수 이름만 암기하지 말고 **무엇을 받아서 어떤 타입으로 돌려주는지** 확인합니다.
각 장의 `assert`는 기대 결과입니다. 예제를 실행했을 때 아무 오류가 없으면 결과가 일치합니다.

| 장 | 도구 | 핵심 구분 |
| --- | --- | --- |
| [집계·정렬·탐색](aggregation-search.md) | len, sum, min/max, sorted, sort, count, index, find, append | 원본 변경과 반환값, 값과 위치 |
| [문자열](strings.md) | join, split, replace, isdigit, upper/lower, isupper/islower, swapcase | 문자열은 불변 |
| [순회·변환·컬렉션](iteration-collections.md) | range, enumerate, map, zip, reversed, int/str, list/tuple, set, dict | iterable과 iterator, 순서 유지 |

복습할 때는 예제의 결과를 먼저 예상한 뒤 실행합니다. 메서드도 코테의 필수 도구지만 내장함수와는 구별합니다.
