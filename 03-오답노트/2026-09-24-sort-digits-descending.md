# 정수 내림차순으로 배치하기

[복습 목차](README.md) · [이전 문제: 자연수 뒤집기](2026-09-24-reverse-digits.md)

- 기록일: 2026-09-24
- 조건: 1 이상 8,000,000,000 이하인 자연수 n의 자릿수를 내림차순으로 배치한 **정수 하나**를 반환.
- 진행: 정렬 아이디어는 맞았으나 join에 정수 원소를 전달했다. 설명을 듣고 사용자가 수정 코드를 작성했다.
- 풀이 시간: 미기록. 플랫폼 제출 통과와 독립 재풀이는 확인하지 않음.

## 먼저 답해 볼 질문

1. `''.join([8, 7, 3])`은 왜 실패하는가?
2. `sorted(str(118372), reverse=True)`의 결과 타입과 각 원소의 타입은?
3. 이번에는 왜 각 문자에 int를 적용하지 않고, 합친 결과에 한 번 적용하는가?
4. 앞의 자연수 뒤집기 문제와 이번 문제는 순서 처리와 반환 타입이 각각 어떻게 다른가?

## 내 시도와 오류 원인

```python
def wrong_solution(n):
    return ''.join(sorted(list(map(int, str(n))), reverse=True))
```

`map(int, str(n))`에서 각 문자를 정수로 바꿔 정렬 결과가 `[8, 7, 3, 2, 1, 1]`이 됩니다.
하지만 **join은 문자열 원소만 합칠 수 있으므로** 이 결과를 받으면 TypeError가 발생합니다.
바깥 list로 감싸도 안쪽 원소의 타입은 정수 그대로입니다.

또한 join에 문자열 원소를 넣도록 고쳐도 반환값은 문자열입니다.
문제는 정수 하나를 요구하므로 마지막에 int 변환이 필요합니다.

## 내가 수정한 답안

```python
def solution(n):
    return int(''.join(sorted(str(n), reverse=True)))

assert solution(118372) == 873211
assert solution(13245) == 54321
assert solution(10200) == 21000
assert solution(7) == 7
assert solution(111) == 111
assert solution(8_000_000_000) == 8_000_000_000
assert type(solution(118372)) is int
```

중간 변수로 나누어 타입을 추적하면 다음과 같습니다.

```python
n = 118372
digits = str(n)
ordered = sorted(digits, reverse=True)
joined = ''.join(ordered)
answer = int(joined)

assert digits == "118372"                      # str
assert ordered == ['8', '7', '3', '2', '1', '1'] # list[str]
assert joined == "873211"                      # str
assert answer == 873211                        # int
```

각 원소가 '0'~'9' 중 한 문자이므로 문자열 정렬과 숫자 크기순 정렬이 일치합니다.
여러 자리 문자열까지 일반화하면 안 됩니다. 예를 들어 문자열 `"10"`은 `"2"`보다 사전순으로 앞섭니다.
sorted는 문자열을 직접 받을 수 있어 정렬 전에 list로 바꾸는 과정도 필요 없습니다.

자릿수 d개를 비교 정렬하는 단계는 O(d log d), 결과 리스트와 문자열의 공간은 O(d)입니다.
이 문제는 자릿수가 최대 10개로 제한되어 있습니다.

## 이 문제에서 가져갈 것

1. join은 **문자열 원소**를 받아 문자열을 만든다. 리스트인지보다 원소의 타입을 확인한다.
2. 정수 배열이 필요하면 문자마다 int, 정수 하나가 필요하면 합친 뒤 int를 적용한다.
3. 한 줄 코드가 막히면 중간 변수로 나누어 값과 타입을 추적한다.
