# 반복과 타입 변환 — 읽고 실행하는 교재

[전체 목차](../../README.md) · [도구 전체 목차](../README.md)

이 폴더의 학습 본문은 모두 **실행 가능한 `.ipynb` 노트북**입니다. 목차는 Markdown으로 유지합니다.
빈칸 문제부터 풀지 않고, **개념 → 완성된 모범 코드 → 실제 값·타입 추적 → 일반 for문 → 주의점** 순서로 읽습니다.

## 처음 읽는 순서

| 순서 | 교재 | 이 장을 읽고 구분할 것 | 따라 읽을 예제 |
| --- | --- | --- | --- |
| 1 | [range — 정수 범위](range.ipynb) | 시작·끝·간격, 인덱스와 값 | 길이가 정해진 부분문자열 |
| 2 | [enumerate — 번호와 값](enumerate.ipynb) | 번호와 원소, start와 슬라이싱 | 문자 위치에 따라 대소문자 바꾸기 |
| 3 | [타입 변환 — int·str·list·tuple](type-conversion.ipynb) | `'1'`과 `1`, 리스트와 원소의 타입 | 자연수의 자릿수 뒤집기 |
| 4 | [map — 원소마다 변환](map.ipynb) | 함수 전달, list와 sum의 역할 | 자릿수 합·하샤드 수·숫자 붙이기 |
| 5 | [zip과 reversed — 함께·역순으로 읽기](zip-reversed.ipynb) | 같은 위치와 모든 조합, 뒤집기와 정렬 | 내적·부호 적용 합산 |
| 6 | [iterable과 iterator — 반복과 소비](iterable-iterator.ipynb) | 다시 읽는 리스트와 소비되는 iterator | 두 번째 map 결과가 빈 이유 |
| 7 | [next — 다음 값 하나](next.ipynb) | 첫 값, 없는 값, 기본값 | 첫 짝수·나머지가 1이 되는 수 |

처음에는 **1~5장을 우선** 읽으세요. map이나 zip의 두 번째 결과가 비어 있는 이유가 궁금해지면 6장을 읽습니다.
7장의 next는 일반 for문 풀이를 이해한 뒤 짧은 코드를 읽는 용도로 연결해도 됩니다.

## 노트북을 읽는 방법

1. 개념을 읽고 바로 아래의 완성된 코드 셀을 실행합니다. 각 코드 셀에 필요한 데이터와 함수를 함께 넣어 **셀 하나만 실행해도 동작**합니다.
2. `# 예상 출력:`과 실제 출력을 비교합니다. 헷갈리면 바로 아래의 값·타입 추적 표를 읽습니다.
3. 일반 for문 풀이와 비교하고, 입력 값 하나를 바꿔 다시 실행해 봅니다. 처음부터 한 줄 코드를 외우지 않아도 됩니다.

코드 셀은 `Shift+Enter`로 실행할 수 있습니다. 노트북에서 Python 3 커널을 선택하세요.
파일에는 실행 결과를 비워 두었으며, 예제는 Python 3.9 이상에서 사용할 수 있는 문법입니다.
실수·빈 입력·복잡도는 핵심 흐름 뒤에 있으니 첫 독서에서 모두 외우려고 하지 않아도 됩니다.
