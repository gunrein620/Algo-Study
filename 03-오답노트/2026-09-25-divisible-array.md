## 내 시도

`sorted([i for i in arr if i % divisor == 0 else -1])`로 작성했습니다.
걸러서 정렬한다는 생각은 맞지만, 필터 역할인 뒤쪽 if에는 else를 붙일 수 없어 SyntaxError가 납니다.

앞쪽에 `i if 조건 else -1`을 쓰면 문법은 맞아도 조건에 안 맞는 원소마다 -1이 들어갑니다.
예를 들어 `[5, 9, 7, 10]`을 5로 검사하면 `[5, -1, -1, 10]`이 되어 문제 요구와 다릅니다.

## 이해하기 쉬운 풀이

```python
def solution(arr, divisor):
    answer = sorted([i for i in arr if i % divisor == 0])
    if not answer:
        return [-1]
    return answer

print(solution([5, 9, 7, 10], 5))  # [5, 10]
print(solution([2, 36, 1, 3], 1))  # [1, 2, 3, 36]
print(solution([3, 2, 6], 10))     # [-1]
```

## 짧은 모범답안

```python
def solution(arr, divisor):
    return sorted([i for i in arr if i % divisor == 0]) or [-1]

print(solution([3, 2, 6], 10))  # [-1]
```

| 단계 | 예시 결과 | 타입 |
| --- | --- | --- |
| 10으로 나누어떨어지는 원소 필터 | [] | list |
| sorted 적용 | [] | list |
| 빈 리스트 or [-1] | [-1] | list |

or는 참/거짓을 판단한 뒤 실제 값을 반환합니다. `[0]`은 비어 있지 않으므로 `[0] or [-1]`은 `[0]`입니다.
사용자는 a가 거짓이면 b가 나온다는 설명을 확인했습니다. 독립 적용 여부는 아직 미확인입니다.
길이 m, 선택된 원소 k개일 때 시간 O(m + k log k), 추가 공간 O(k)입니다(상수 크기 기본값 별도).
