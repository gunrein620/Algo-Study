# Python 코딩테스트 교과서 & 복습노트

알고 있는 아이디어를 **Python 코드로 바로 옮기기 위한 개인 교과서**입니다.

## 이렇게 사용하기

1. **처음 배우는 함수**: 해당 장의 용도 → 문법 → 예제 → 경계 조건을 읽습니다.
2. **문제를 푼 직후**: 어떤 패턴인지 찾고, 가져갈 것 1~3개만 기록합니다.
3. **다음 날 복습**: 답을 가린 채 복습 질문을 설명하고 짧은 코드를 다시 작성합니다.
4. **일주일 뒤**: 비슷한 문제에서 도움 없이 같은 도구를 선택할 수 있는지 확인합니다.

예제는 Python 3.9 이상을 기준으로 합니다(`math.lcm` 사용). 플랫폼의 실제 Python 버전은 제출 전에 확인합니다.
`count`, `join`, `sort`는 객체의 **메서드**, `sum`, `sorted`는 **내장함수**, `Counter`는 **표준 라이브러리**입니다.

## 학습 방향

Lv.0으로 문법과 구현 감각 회복 → Lv.1 짧은 구현 → Lv.2 핵심 유형 → 쉬운 Lv.3·기업 기출.
Lv.0 무작위 10문제 중 7~8개를 5분 안에 도움 없이 구현하면 다음 단계로 넘어가는 기준으로 삼습니다.
