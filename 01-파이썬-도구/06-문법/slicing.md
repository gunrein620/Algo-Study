## 먼저 구분하기: 한 개 꺼내기와 구간 꺼내기

문자열이나 리스트의 위치는 0부터 셉니다. 음수 위치는 오른쪽 끝을 -1로 놓고 셉니다.

| 문자 | a | b | c | d | e | f |
| --- | --- | --- | --- | --- | --- | --- |
| 앞에서 센 위치 | 0 | 1 | 2 | 3 | 4 | 5 |
| 뒤에서 센 위치 | -6 | -5 | -4 | -3 | -2 | -1 |

```python
s = "abcdef"
print(len(s))   # 6
print(s[2])     # c
print(s[-4])    # c
print(s[-4:])   # cdef
print(s[:-4])   # ab
print(s[1:4])   # bcd
```

`[2]`는 한 개를 꺼내는 인덱싱이고, `[1:4]`는 여러 원소의 구간을 꺼내는 슬라이싱입니다.
**시작 위치는 포함하고 끝 위치는 제외**하므로 1, 2, 3번 위치의 bcd를 얻습니다.
문자열에서는 문자 하나도 문자열입니다.

## 시작·끝·간격을 따로 읽기

| 문법 | 읽는 법 |
| --- | --- |
| `s[시작:끝]` | 시작부터 끝 직전까지, 한 칸씩 오른쪽으로 |
| `s[시작:]` | 시작부터 마지막까지 |
| `s[:끝]` | 처음부터 끝 직전까지 |
| `s[::간격]` | 기본 범위 전체를 지정한 간격으로 |

`[-4:]`는 **뒤에서 네 번째 위치부터 끝까지**입니다. 음수는 위치를 나타냅니다.
`[::-1]`은 **간격이 -1이므로 전체를 거꾸로** 읽습니다. 음수의 자리가 다릅니다.

```python
s = "abcdef"
print(s[-4:])   # cdef
print(s[::-1])  # fedcba
print(s)        # abcdef
```

슬라이싱으로 읽어도 원본은 변경되지 않습니다.

## 자주 쓰는 리스트 예제와 경계 조건

`arr[start:end:step]`은 지정한 구간을 추출합니다. 리스트는 새 리스트(얕은 복사), 문자열은 문자열입니다.
범위를 넘어가는 슬라이스는 잘라서 처리하지만, 단일 인덱싱은 범위를 벗어나면 IndexError입니다.
step은 0일 수 없습니다. 음수 step에서는 진행 방향도 반대입니다.

```python
arr = [1, 2, 3, 4, 5]
print(arr[1:4])  # [2, 3, 4]
print(arr[:3])  # [1, 2, 3]
print(arr[2:])  # [3, 4, 5]
print(arr[:])  # [1, 2, 3, 4, 5]
print(arr[::2])  # [1, 3, 5]
print(arr[::-1])  # [5, 4, 3, 2, 1]
print(arr[:-1])  # [1, 2, 3, 4]
print(arr[-1:])  # [5]
print(arr[99:])  # []
print([][-1:])  # []
```

`arr[-1]`은 마지막 **값** 5, `arr[-1:]`은 마지막 원소를 담은 **리스트** `[5]`입니다.
추출 길이가 k인 리스트/문자열 슬라이스는 일반적으로 O(k) 시간과 결과 공간이 필요합니다.
적용 예시: [한 칸 회전](../../02-풀이-패턴/06-rotate.md) · [묶음 자르기·일정 간격 추출](../../02-풀이-패턴/07-chunk-step.md).

### 함수 반환값에도 바로 슬라이싱하기

`[]`는 변수 이름 뒤에만 붙이는 문법이 아닙니다. **계산 결과가 문자열이나 리스트처럼
슬라이싱을 지원하는 값이면 그 표현식 뒤에 바로 붙일 수 있습니다.**

```python
n = 13245
s = str(n)
reversed_s = s[::-1]
print(reversed_s)  # 54231
print(str(n)[::-1])  # 54231
print(str(n)[0])  # 1
print(str(n)[1:3])  # 32
```

`str(n)[::-1]`은 `str(n)`을 먼저 계산하고, 반환된 `"13245"`에 `[::-1]`을 적용합니다.
즉 `"13245"[::-1]`과 같고 결과는 문자열 `"54231"`입니다. 중간 변수에 저장하는 단계를 생략한 것입니다.
함수라서 가능한 것이 아니라 **반환값이 슬라이싱을 지원하기 때문에** 가능합니다.
예를 들어 `len("abc")`는 정수 3을 반환하므로 뒤에 `[::-1]`을 붙이면 TypeError입니다.

`[::-1]`에서는 start와 end를 생략하고 step을 -1로 지정합니다.
음수 방향의 기본 범위 전체를 한 칸씩 거꾸로 읽으므로 방문 인덱스는 4 → 3 → 2 → 1 → 0입니다.
문자열을 뒤집어도 결과는 문자열이고, 원본은 변하지 않습니다. 빈 문자열은 그대로 빈 문자열입니다.

**정렬과 뒤집기도 구분합니다.** `sorted(..., reverse=True)`는 값의 크기에 따라 재배치하고,
`[::-1]`은 현재 순서만 반대로 만듭니다.

```python
print(sorted('13245', reverse=True))  # ['5', '4', '3', '2', '1']
print('13245'[::-1])  # 54231
print(''[::-1])  # 빈 문자열
```

적용 사례: [자연수 뒤집기 리뷰](../../03-오답노트/2026-09-24-reverse-digits.md).

## 마지막 몇 글자만 남기기

```python
phone_number = "321432"
hidden = '*' * (len(phone_number) - 4)
last_four = phone_number[-4:]
print(hidden + last_four)  # **1432
```

문자열에 정수를 곱하면 그 횟수만큼 반복한 문자열이 됩니다. 0번 반복하면 빈 문자열입니다.
이 문제에서는 길이가 4 이상이므로 별표 개수가 음수가 되지 않습니다.
